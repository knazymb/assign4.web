HTML and Bootstrap Forms Assignment


Description


This project contains five tasks about HTML forms, HTML5 validation, Bootstrap form styling, Bootstrap validation feedback, and a registration form.

Project Structure

index.html - Main page with navigation links


task0.html - Simple Contact Form


task1.html - HTML5 Form Validation


task2.html - Bootstrap Form Styling


task3.html - Bootstrap Validation Styles


task4.html - Registration Form


style.css - Shared CSS styles


script.js - Form validation using JavaScript



Technologies

HTML5

CSS3

Bootstrap 5

JavaScript



How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the navigation bar to open each task.
5. Make sure you have an internet connection to load Bootstrap from the CDN.

Features


Contact forms with labels


HTML5 form validation


Responsive Bootstrap grid layout


Validation feedback messages


Registration form with password confirmation


Navigation between all task pages
